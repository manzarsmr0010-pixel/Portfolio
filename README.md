# Cinematic Portfolio Landing Page

## Run it
Open `index.html` in a modern browser. GSAP, ScrollTrigger, and Lenis load from CDNs, so an internet connection is needed for the animations.

## Customize first
- Replace `YOUR NAME` in the HTML with your name.
- Change `DIGITAL CREATOR` to your role.
- Update the hero intro and the three episode cards.
- Change `hello@example.com` to your email.
- The hero artwork is made with CSS shapes, so no external image is required.

## Included motion
- GSAP intro timeline and staggered headline reveal
- ScrollTrigger hero parallax and reveal animations
- Lenis smooth scrolling
- Tilt effect on content cards
- Magnetic hover buttons
- Reduced-motion accessibility fallback

This is the landing page starter only. The project/story/skills cards are placeholders for the next phase.
